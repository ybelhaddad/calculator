# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Getting started

1. Fork or clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev -- -p 3847
   ```

4. Open [http://127.0.0.1:3847](http://127.0.0.1:3847) and make your changes.

## Guidelines

- Keep the calculator focused on simple interest: `SI = (P × R × T) / 100`.
- Prefer clear, small changes with a short description of what changed and why.
- Update the README when behavior, usage, or setup steps change.
- Run `npm run lint` and `npm run build` before submitting.

## Pull requests

Open a pull request against the default branch with a brief summary of the change. Include screenshots for UI updates when helpful.
